# StableAFM

> A physics-guided generative diffusion model for super-resolution atomic force
> microscopy of trap dynamic behavior.

[![Project status: pre-release](https://img.shields.io/badge/status-pre--release-orange)](#project-status)
[![License: Apache-2.0](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

StableAFM is the model accompanying the paper **“A Physics-Guided Generative
Diffusion Model for Super-Resolution AFM of Trap Dynamic Behavior.”**

StableAFM 是论文 **《A Physics-Guided Generative Diffusion Model for
Super-Resolution AFM of Trap Dynamic Behavior》** 对应的开源项目。

## Project status

**Pre-release.** The paper, model implementation, training and evaluation code,
configuration files, and reproducibility instructions are currently being
organized for public release.

论文、模型实现、训练与评估代码以及复现说明正在整理中。请关注本仓库的后续更新。

## Planned release

- StableAFM model architecture and physics-guided objectives
- Training, validation, and inference pipelines
- Reproducible experiment configurations
- Data preparation and AFM preprocessing guidance
- Evaluation metrics and paper figure reproduction scripts
- Model checkpoints and a model card, subject to distribution constraints
- Example inputs and outputs that can be redistributed publicly

## Installation and usage

Installation instructions and runnable examples will be added with the first
code release. Until then, this repository does not provide an installable
package or pretrained checkpoint.

## Data and checkpoints

Raw AFM data, derived datasets, experiment outputs, and model weights are not
included in the initial repository. Their availability, licensing, and access
instructions will be documented before release. Please do not commit sensitive,
restricted, or non-redistributable research data.
